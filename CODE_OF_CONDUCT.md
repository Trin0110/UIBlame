# Code of Conduct

UIBlame follows a simple standard: be constructive, specific, and respectful.

Contributors should discuss code and ideas without harassment, personal attacks, discrimination, or deliberate disruption. Security and provenance discussions can involve disagreements about trust; challenge the evidence or design, not the person.

Maintainers may edit, hide, lock, or remove abusive or spam content and may restrict participation when necessary to keep the project usable.

For security-sensitive reports, use the process in [SECURITY.md](SECURITY.md) rather than posting secrets publicly.
